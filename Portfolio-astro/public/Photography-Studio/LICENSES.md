# Assets and licences

Check this list before a template goes to a client. A client site should ship only assets you own or have a licence for.

| Asset | Where | Source and licence |
|---|---|---|
| Photographs | `img/photos/` | The template owner's own photographs. Replace them with the client's photos. A visible person needs their permission (see `photo-inbox/README.md`). |
| Fox and fern artwork | `img/fox.webp`, `img/leaf-1.webp`, `img/leaf-2.webp` | Created by the template owner. No outside licence applies. |
| Walking fox | `img/fox-walk.svg` | Drawn for this template. |
| Film grain | `img/grain.png` | Generated noise, no outside source. |
| Favicon | `img/favicon.svg` | Drawn for this template. |
| Montserrat | `fonts/montserrat-*.woff2` | SIL Open Font License 1.1 (Google Fonts). Confirm on fonts.google.com before shipping. |
| Frank Ruhl Libre | `fonts/frank-ruhl-libre-*.woff2` | SIL Open Font License 1.1 (Google Fonts). Confirm before shipping. |
| Great Vibes | `fonts/great-vibes.woff2` | SIL Open Font License 1.1 (Google Fonts). Trimmed to Latin letters to save weight. Confirm before shipping. |
| Code | everything else | Written for this template. |
| Editor | `admin/decap-cms.js` (copied from the `decap-cms` npm package at build) | Apache License 2.0. Used as shipped; it is not committed to the repository. |

The font licences above are from memory of the Google Fonts listings; verify them and keep a copy of each licence text with a client's site if the licence asks for it.
