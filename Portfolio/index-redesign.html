Design notes — what changed from the current page, and why
  • Dropped the stock illustration. The "undraw" person-next-to-a-UI-card graphic is generic — it's on thousands of other sites and says nothing about you specifically. Replaced it with a small status-panel motif (uptime / environments / deploys / IaC coverage) built from plain CSS, not an imported graphic — it's a visual that only makes sense on an SRE's site.
  • Dropped the neon cyan→magenta gradient heading. It read as a generic "dev portfolio template" cue. Replaced with a small accent-colored kicker label ("SITE RELIABILITY ENGINEER") above a solid-color serif name — a more restrained, editorial hierarchy that still uses your existing brand font and accent blue.
  • Skill list → monospace tags (#aws #iac #gitops #webdev) instead of three stacked lines. Reads more like infrastructure-as-code shorthand, which fits the role, and takes a third of the vertical space.
  • Added real call-to-action buttons ("Get in Touch", "View GitHub") instead of only two small icon links — gives a first-time visitor an obvious next action instead of making them hunt for the social icons.
  • Swapped the big gradient-blob background for a subtle dot-grid. Same idea (a textured backdrop behind the hero) without the "AI-gradient" look, and it's theme-aware instead of hardcoded.
  • Everything else is untouched — same rail nav, same footer, same fonts, same light/dark system. This is a hero-section concept only, not a navigation or information-architecture change.
