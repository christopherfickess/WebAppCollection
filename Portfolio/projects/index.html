Starlight — Personal Kubernetes Homelab

A self-hosted Kubernetes cluster run the way production infrastructure should be: every change goes through Flux and a pull request, nothing gets applied by hand. It's where I test ideas before they go near a real environment — GitOps workflows, policy enforcement, zero-trust networking — and where a few of my own tools actually run.

  • GitOps — every change through Flux + a PR, nothing applied by hand
  • Zero-trust networking — admin surfaces are Tailscale-only, never public
  • Policy & runtime security — Kyverno, Tetragon (eBPF), Trivy scanning
  • Full observability — Grafana, Prometheus, Loki, Alertmanager
